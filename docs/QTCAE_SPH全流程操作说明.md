# QTCAE SPH 全流程操作说明

## 1. 适用范围

本说明适用于 QTCAE 当前的三维显式 SPH 流程：

1. 导入一个或多个一阶四面体 HMASCII 网格；
2. 在 QTCAE 中设置每个部件的动力学材料、位置、初速度和接触参数；
3. 生成 `configure.xml`、部件网格副本和材料文件；
4. 启动独立的 `sphSolver.exe` 进程；
5. 在任务监控中查看计算状态；
6. 计算完成后自动切换到后处理并加载 VTU/PVD 结果。

当前求解器支持三维、一阶四面体材料点、J2 幂律材料和 Mie-Grüneisen 状态方程。多部件采用无摩擦法向罚接触，尚不包含切向摩擦、粘结或接触失效模型。

## 2. 开始前检查

- 已能启动 `QTCAE.Workbench.exe`；
- 已编译 `sphSolver.exe`；
- 网格为一阶四面体 HMASCII 文件（`.hm`、`.hmascii` 或兼容文本）；
- 网格单位与作业单位一致。当前配置按毫米几何、SI 材料参数和 m/s 初速度解释；
- 大算例建议先执行少量步数试算，再完整运行。

## 3. 导入网格

1. 启动 QTCAE，保持在“前处理”工作区；
2. 打开“网格”菜单；
3. 点击“导入 HMASCII 网格”；
4. 选择第一个部件网格；
5. 多部件算例重复上述操作，依次导入其余部件；
6. 在工程树“模型 → 网格”中确认每个部件均存在，节点数和四面体数大于零。

同名文件也可以导入。SPH 作业内部以网格对象 ID 和部件顺序区分，不以显示名称作为唯一标识。

## 4. 创建并运行 SPH 作业

1. 打开“分析”菜单；
2. 点击“设置并运行 SPH 分析”；
3. 在“作业”页设置：
   - 作业名称；
   - 作业目录；
   - `sphSolver.exe` 路径；
   - 物理终止时间；
   - 稳定时间步比例；
   - 结果输出间隔；
   - 本次最多计算步数；
   - 线程数；
   - 部件接触类型。
4. 在“部件”页：
   - 勾选本次参与计算的部件；
   - 逐个选择部件；
   - 设置部件名称、材料、网格平移、初速度、人工黏性和沙漏系数；
   - 需要兼容原文件节点集时勾选“保留并应用已知 HMASCII 节点集约束”；
   - 需要写入原算例的节点接触参数时勾选“写入节点接触组参数”。
5. 在“求解控制”页设置邻域搜索、质量因子、临界应变和无锁定修正；
6. 泰勒杆算例在“刚性平面”页启用所需的无限刚性平面；
7. 点击“生成并运行”。

“本次最多计算步数”为 0 时，求解器按物理终止时间完整运行；设置为正整数时，用于快速试算并通过 `--steps` 限制本次步数。试算不会修改生成的物理终止时间。

## 5. 泰勒杆撞击建议设置

仅勾选泰勒杆网格：

| 参数 | 建议值 |
|---|---:|
| 材料模板 | 铜 OFHC |
| 初速度 | `(0, 0, -227)` m/s |
| 物理终止时间 | `8e-5` s |
| 时间步比例 | `0.2` |
| 输出间隔 | `200` 步 |
| 临界应变 | `0.2` |
| 刚性平面 1 | 原点 `(0,0,0)`，法向 `(0,0,1)`，刚度 `5e9` Pa |
| 刚性平面 2（如需导向） | 原点 `(0,0,0)`，法向 `(1,0,0)`，刚度 `1e9` Pa |
| 刚性平面 3（如需导向） | 原点 `(0,0,0)`，法向 `(0,1,0)`，刚度 `1e9` Pa |

首次验证把“本次最多计算步数”设为 5～100；确认结果正常后设为 0 完整运行。

## 6. 金属杆撞击蒙皮（Fragment）建议设置

按照工程树中的网格顺序确认“弹体”和“蒙皮”，不要仅凭默认部件名称判断。

### 全局参数

| 参数 | 建议值 |
|---|---:|
| 物理终止时间 | `0.001` s |
| 时间步比例 | `0.1` |
| 输出间隔 | `5000` 步（试算可减小） |
| 邻域搜索范围 | `1.5` |
| 搜索扩展系数 | `2.1` |
| 核函数 γ | `1.6` |
| 质量因子 | `0.01` |
| 临界邻居数 | `8` |
| 临界应变 | `0.3` |
| 线程数 | `16` 或不超过本机逻辑线程数 |
| 无锁定修正 | 启用 |
| 部件接触 | 无摩擦法向罚接触 |

### 弹体部件

| 参数 | 建议值 |
|---|---:|
| 材料模板 | 钢（Fragment 算例） |
| 网格平移 | `(0, 4, 8)` mm |
| 初速度 | `(0, 0, -770)` m/s |
| 能量释放率 | `1e16` |
| 人工黏性 α / β | `0.01 / 0.1` |
| 沙漏系数 | `1` |
| 节点接触组 | 启用，`50 / 0.5 / 5000` |

### 蒙皮部件

| 参数 | 建议值 |
|---|---:|
| 材料模板 | 铝 2024-T4（Fragment 算例） |
| 网格平移 | `(0, 0, 0)` mm |
| 初速度 | `(0, 0, 0)` m/s |
| 能量释放率 | `1e16` |
| 人工黏性 α / β | `0.01 / 0.1` |
| 沙漏系数 | `20` |
| 节点接触组 | 启用，`50 / 0.5 / 5000` |

首次验证建议把“本次最多计算步数”设为 10～100。完整 `0.001 s` 大网格计算可能需要数小时，确认试算中的运动方向、接触力、能量和输出字段正常后再设为 0。

## 7. 运行监控与停止

- 求解器启动后，“任务监控”显示作业状态和进度；
- “消息日志”显示配置路径、输出目录、求解器诊断和警告；
- 需要中止时点击“停止当前 SPH 分析”；
- QTCAE 会先请求正常终止，超时后结束求解进程；
- 不要在求解运行时删除作业目录或覆盖网格/材料文件。

## 8. 后处理

成功结束后 QTCAE 自动：

1. 扫描作业目录下的 `output`；
2. 识别 `solid_results.pvd` 和各帧 VTU；
3. 切换到“后处理”；
4. 加载各部件和当前帧；
5. 保留现有云图、变形、部件显隐及帧切换功能。

重点检查：

- 总点数、活动单元数和部件数是否符合预期；
- 位移方向是否与初速度一致；
- 接触力是否在碰撞后出现；
- Mises 应力、塑性应变、能量和失效粒子数量是否有限且物理趋势合理；
- 多部件结果是否均存在，未因全局色标范围而误判某个部件“没有应力”。

## 9. 作业文件

每次生成的作业目录包含：

```text
作业目录/
├── configure.xml
├── body_0.hmascii
├── body_0_material.dat
├── body_1.hmascii
├── body_1_material.dat
└── output/
    ├── solid_results.pvd
    ├── solid_*.vtu
    └── diagnostics.csv
```

配置使用相对文件名，因此整个作业目录可以整体复制到其他位置运行。不要只复制 `configure.xml`。

QTCAE 新生成的配置以 `<QTCAE>` 作为根节点，配置常量统一使用 `QTCAE_` 前缀。历史配置仅由求解器兼容读取；QTCAE 不会在界面、日志、文档或新作业文件中写入其他软件的品牌名称。

## 10. 当前限制

- 只支持一个材料组对应一个 SPH 部件；
- 只支持一阶四面体；
- 多部件接触仅包含无摩擦法向罚接触；
- `Critical_NumofNeighbors` 当前保留兼容，但不参与现行失效判据；
- `Energy_Release_Rate` 当前保留兼容，但不参与现行侵蚀模型；
- 尚无接触参数自动标定、局部时间步可视化和求解前穿透检查；
- 完整 Fragment 大网格结果需以长时间计算实测为准，少量步数试算不能替代最终物理验收。
